Use this page to choose a command. The [CLI reference](/packages/cli) contains
detailed flags, examples, and environment settings. The installed version
remains authoritative: run `hyperframes <command> --help`.

## Everyday project loop

| Task | Command |
| --- | --- |
| Create a project | `hyperframes init my-video` |
| Open Studio | `hyperframes preview` |
| Check HTML structure | `hyperframes lint` |
| Run browser, layout, motion, and contrast checks | `hyperframes check` |
| Capture review frames | `hyperframes snapshot --at 0,2,5` |
| Render a video | `hyperframes render --output output.mp4` |
| Diagnose the machine | `hyperframes doctor` |
| Free disk space HyperFrames used | `hyperframes clean` |

## Work with media

| Task | Command |
| --- | --- |
| Inspect project metadata | `hyperframes info` |
| Transcribe speech | `hyperframes transcribe <file>` |
| Generate narration | `hyperframes tts <script>` |
| Capture a website | `hyperframes capture <url>` |

## Reuse and inspect

| Task | Command |
| --- | --- |
| Add a Catalog item | `hyperframes add <name>` |
| List compositions | `hyperframes compositions` |
| Print tracks and clips | `hyperframes timeline` (`--json` for agents) |
| Inspect keyframe behavior | `hyperframes keyframes` |
| Compare two or more versions | `hyperframes compare v1/ v2/` |

`hyperframes timeline` also accepts agent editing verbs. Use `move`, `trim`, `split`, or `delete` with a row ref; add `--plan` to inspect the before/after rows and diff without writing, or `--json` for a machine-readable receipt. Time values accept seconds, relative offsets, frames, and anchors such as `after:#intro`.

## Rendering and automation

The CLI also renders in batches and from variables, writes image sequences and
several video formats, and runs in the cloud on AWS Lambda or Google Cloud Run. Most commands take `--json` when you need to read the result from a script.

Start with the simple command, then open the [full reference](/packages/cli) for the exact options needed by automation or infrastructure.

<Tip>
  Run `hyperframes <command> --help` for the installed version’s exact syntax.
</Tip>
